Adapted from https://github.com/thesysdev/open-intelligent-ui at `03213439358bf3408ad61a46ec9e3230c5572e48` (MIT).

Reused: layout, controls, SVG, charts, and the generic function library.
Socrates supplies its own token-based styles, text/media components, bounded
styles/URLs, action bridge, lazy loading, and prose/fence integration.

This is a curated component library. The upstream Next.js shell, telemetry,
cloud gateway, external embeds and HtmlView are not included. Maps and image search use
Socrates-owned adapters based on the upstream map/geometry design, with
authenticated same-origin provider endpoints, source attribution and retries. No Thesys account or additional model key is required.
