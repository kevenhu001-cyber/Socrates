Error Responses

HTTP status pages

A collection of error response pages designed in the Socrates visual style. Each page provides clear feedback and a helpful path forward.

401

Unauthorized

Authentication required. The request lacks valid credentials.
403

Forbidden

Access denied. You don't have permission to access this resource.
404

Not Found

The page or resource you're looking for doesn't exist.
429

Too Many Requests

Rate limit exceeded. Please wait and try again.
500

Internal Server Error

Something went wrong on our end. We're working on it.
503

Service Unavailable

The service is temporarily down for maintenance or overload.
