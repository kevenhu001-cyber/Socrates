For developers

Build around the question, not just the answer.

Use the model you trust. Socrates keeps the learning state structured and portable.

curl https://api.socrates.ai/v1/dialogue \
  -H "Authorization: Bearer $YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "message": "Why does the limit exist?",
    "context": { "topic": "limits" },
    "mode": "dialogue"
  }'
from socrates import Client

client = Client()
dialogue = client.dialogue.create(
  message="Why does the limit exist?",
  topic="limits",
  mode="dialogue"
)
print(dialogue.next_question)
const dialogue = await socrates.dialogue.create({
  message: "Why does the limit exist?",
  context: { topic: "limits" },
  mode: "dialogue"
});

console.log(dialogue.nextQuestion);
