Quickstart

Three steps to your first agent call.

  1. Pick an auth route. Third-party agents use the OAuth 2.0 authorization-code flow with PKCE. First-party automation mints a scoped key in the app or via the API (POST /api/account/agent-keys) and calls with Authorization: Bearer ak_<keyId>.<secret>.
  2. Read the contract. Every public endpoint is specified in the OpenAPI 3.0 specification — operationIds, request/response schemas, error codes, and per-operation OAuth scopes.
  3. Call the API. Base URL https://app.topodrive.top. Health probe first: GET /api/v2/health. Rate-limit headers (RateLimit-Limit / -Remaining / -Reset) ride every response so you can self-throttle.

Conventions

What every endpoint has in common.

  • Typed errors. Failures return one shape: {"code": "MACHINE_READABLE_CODE", "message": "human detail", "detail": …} with the right status — 400 validation, 401 UNAUTHORIZED (+ RFC 6750 WWW-Authenticate challenge), 403 INSUFFICIENT_SCOPE, 404 NOT_FOUND, 429 TOO_MANY_REQUESTS (+ Retry-After).
  • Scopes. OAuth tokens and agent keys carry grants from a closed set (chat:read/write, sessions:…, memory:…, files:…, projects:…). Read methods demand :read, mutations demand :write; the OpenAPI file declares the scope per operation.
  • Idempotency. Send Idempotency-Key: <uuid> on any write; replays within 24 h return the original response instead of duplicating work. Declared on every mutating operation in the spec.
  • Rate limits. Standard RateLimit-Limit, RateLimit-Remaining, RateLimit-Reset headers; honor them and you will not see 429.
  • Pagination. List endpoints answer with {items, cursor, hasMore}; pass ?cursor= back until hasMore is false.
  • Long jobs. Bulk imports return 202 Accepted with {jobId, status}; poll GET /api/import/:id until status: completed.
  • Versioning. The current surface is unversioned-at-root with a versioned mobile contract under /api/v2/*. Deprecations are announced by adding a Sunset header (HTTP date) and a note in announcements at least 90 days before removal.
