指南

几分钟即可开始学习

上手 Socrates 非常简单。只需带上你自己的大语言模型 API 密钥，以及一个你想探索的主题。以下是入门所需的一切——从设置到第一节课。

1

打开应用

访问 app.topodrive.top。无需下载，无需安装——任何现代浏览器（Chrome、Firefox、Safari、Edge）均可使用。界面分为侧边栏（会话历史、设置、知识图谱）和主区域（课程展开的地方）。在移动端，侧边栏会收起，主视图占满全屏——点击汉堡图标即可切换。

2

配置提供商

点击左下角的齿轮图标打开 API 设置。Socrates 支持 OpenAI（GPT-5.5）、Anthropic（Claude Opus 4.8、Sonnet 4.6）以及任何 OpenAI 兼容端点（Together.ai、Groq、DeepSeek、通过 vLLM/Ollama 运行的本地大模型）。

获取密钥：访问 platform.openai.com 或 console.anthropic.com，创建 API 密钥并粘贴到设置中。免费套餐支持 1 个密钥；付费套餐最多支持无限个密钥，可跨不同提供商使用。你也可以启用内置的模拟模式，无需任何设置即可体验应用。

3

选择主题

在屏幕中央的输入框中输入任何你想学习的内容。Socrates 适应任何学科——从微积分到诗歌，从量子力学到哲学，从机器学习到音乐理论。一些示例：

  • "用物理实例讲解链式法则"
  • "教我了解拜占庭帝国——重点讲贸易路线"
  • "我想理解深度学习中的 Transformer 原理"
  • "带我梳理约翰·斯图尔特·密尔的功利主义"
4

按自己的节奏学习

Socrates 从结构化讲解开始，逐个引入概念，配以清晰的定义、具体的实例和与前置知识的关联。数学公式通过 LaTeX 精美渲染。代码块带有语法高亮。每个章节读起来都像精心撰写的教科书——只不过它是专为你而写。

每个关键概念之后，Socrates 都会提出诊断问题。答对即可进入下一层。答错则导师会换个角度重新审视——替代解释、不同示例或更基础的知识回顾。没有两条学习路径是完全相同的。

5

创建账号（可选）

用邮箱注册即可跨设备同步会话并保存学习历史。验证很快——查收收件箱中的确认链接即可。验证通过后，你的会话、知识图谱和错题本都会备份到服务器。不注册的话，会话保存在浏览器本地，清除数据后可能会丢失。

使用技巧

充分发挥 Socrates 的价值

尽量具体
主题越窄，课程越深。与其输入"数学"，不如尝试"从第一性原理讲解链式法则，并配以物理实例"。
诚实作答
诊断问题检验的是你的理解，而非自尊。不确定时猜对会跳过你真正需要的内容。
回顾错题
错题本记录了你答错的每一道题。定期回顾，巩固薄弱环节。
