指南

几分钟即可开始学习

上手 Socrates 非常简单。内置 Beagle AI 模型开箱即用，无需 API 密钥。只需选一个主题，即可开始学习。以下是入门所需的一切，从设置到第一节课。

1

打开应用

访问 app.topodrive.top。无需下载，无需安装，任何现代浏览器（Chrome、Firefox、Safari、Edge）均可使用。界面分为侧边栏（会话历史、设置、知识图谱）和主区域（课程展开的地方）。在移动端，侧边栏会收起，主视图占满全屏，点击汉堡图标即可切换。

2

配置提供商

Socrates 内置了 Beagle AI 模型，立即可用，无需任何配置。如果你更喜欢使用自己的模型，点击左下角的齿轮图标打开 API 设置。Socrates 也支持 OpenAI（GPT-5.5）、Anthropic（Claude Opus 4.8、Sonnet 4.6）以及任何 OpenAI 兼容端点（Together.ai、Groq、DeepSeek、通过 vLLM/Ollama 运行的本地大模型）。

获取密钥：访问 platform.openai.com 或 console.anthropic.com，创建 API 密钥并粘贴到设置中。免费套餐最多支持 2 个密钥；付费套餐最多支持无限个密钥，可跨不同提供商使用。

3

选择主题

在屏幕中央的输入框中输入任何你想学习的内容。Socrates 适应任何学科，从微积分到诗歌，从量子力学到哲学，从机器学习到音乐理论。一些示例：

  • "用物理实例讲解链式法则"
  • "教我了解拜占庭帝国，重点讲贸易路线"
  • "我想理解深度学习中的 Transformer 原理"
  • "带我梳理约翰·斯图尔特·密尔的功利主义"
4

按自己的节奏学习

Socrates 从结构化讲解开始，逐个引入概念，配以清晰的定义、具体的实例和与前置知识的关联。数学公式通过 LaTeX 精美渲染。代码块带有语法高亮。每个章节读起来都像精心撰写的教科书，而且是专为你而写的。

每个关键概念之后，Socrates 都会提出诊断问题。答对即可进入下一层。答错则导师会换个角度重新审视，提供替代解释、不同示例或更基础的知识回顾。没有两条学习路径是完全相同的。

你还可以切换到考试模式，通过结构化测评检验知识水平。在任意主题上生成考试，设置难度和题型，按自己的节奏作答，提交后自动评分。每道答过的题都会记录到错题本中，方便日后回顾。

5

创建账号

使用 Socrates 需要先注册账号。用邮箱注册即可开始学习——验证很快，查收收件箱中的确认链接即可。验证通过后，你的会话、知识图谱、错题本和 API 密钥都会备份到服务器，并可在不同设备间同步。

使用技巧

充分发挥 Socrates 的价值

尽量具体
主题越窄，课程越深。与其输入"数学"，不如尝试"从第一性原理讲解链式法则，并配以物理实例"。
诚实作答
诊断问题检验的是你的理解，而非自尊。不确定时猜对会跳过你真正需要的内容。
回顾错题
错题本记录了你答错的每一道题。定期回顾，巩固薄弱环节。
