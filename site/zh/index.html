查看套餐

Socrates 免费吗？

是的。免费档永久免费，不绑卡即可开始提问。付费档提供更多额度和工具。

Socrates 会用我的对话来训练吗？

不会。我们不会用你的对话来训练。你可以随时从账户页导出或删除任意会话。

我可以使用自己的 API 密钥吗？

可以。免费档和每个付费档都支持为任意受支持的 provider 自带 API 密钥。

我可以随时取消吗？

可以。从账户页取消，套餐会保留到当前周期结束。没有挽留电话，也没有截止陷阱。

如果我改主意了怎么办？

如果你在首次付费套餐的十四天内取消，写信给我们，我们会退还该周期。

你们支持发票和 VAT 吗？

支持。从账户页添加账单信息，欧盟客户在需要时会按 VAT 计费。
