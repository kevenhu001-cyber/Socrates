路径，而非摘要

通往一个想法的路径始终可见，你可以回到推理本身，而不是一个被压平的答案。

在对的间隔回忆

有用的时刻会变成小提示，出现在提取仍然需要费力的那个点上。

一张与你一起生长的地图

问题会跨会话连接。地图围绕你的兴趣生长，而不是一套固定的课程。

四个产品区块

一段对话，四种注意力。

对话、回忆、知识地图与练习不是四个独立功能，而是同一个循环的四个侧面。

01

对话

停留在那个还说不通的地方。导师跟随你的推理，给出更锋利的问题。

02

回忆

在一个想法淡去之前，把它带回来。回忆提示让你用自己的话重新回答有用的时刻。

03

知识地图

看见正在学习的事物之间那条线。问题会跨会话形成一张不断生长的地图。

04

练习

不必表演确定，也能确认自己懂了。低压力的问题会揭示什么已经成立、什么还缺一块。

在对话中

常见问题

一些常见问题。

关于使用的几个实际问题，简短回答。其余都在产品里。

Socrates 免费吗？
是的——Free 方案永久免费。付费方案解锁更多容量与工具。
会用我的对话训练模型吗？
不会。我们不会用用户对话训练模型。每个会话都可以从账户页面导出或删除。
可以自带 API Key 吗？
可以。Free 方案和所有付费方案都支持 BYOK（自带密钥），适用于任何受支持的服务商。
支持发票和增值税吗？
支持。在账户页面填写账单信息；欧盟客户会按适用规定计入增值税。
