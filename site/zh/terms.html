2. 服务描述

Socrates 是一个基于人工智能的苏格拉底式辅导平台。该服务使您能够通过将自有的大型语言模型（LLM）提供商 API 密钥连接到我们的专有教学引擎，参与结构化、自适应的学习会话。

BYOK 模式。 该服务采用自带密钥（BYOK）模式运行。您负责从支持的第三方 LLM 提供商处获取并维护您自己的 API 密钥，包括但不限于 OpenAI、Anthropic 及兼容 OpenAI 的端点。我们从不收取模型推理费用；您直接向您的 LLM 提供商支付通过服务产生的使用费用。

修改。 我们保留随时修改、暂停或终止服务任何部分的权利，无论是否事先通知。对于实质性减损您访问权的重大变更，我们将尽商业上合理的努力提前通知。对于服务的任何修改、暂停或终止，我们对您或任何第三方不承担任何责任。
