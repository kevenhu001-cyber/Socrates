Socrates 如何使用你的密钥

一份关于发送内容与不发送内容的简短说明。

你的密钥只会发往你选择的供应商，并且只会带上你会话中产生的提示词。我们不会通过自己的服务器转发流量，不记录你的提示，也不会附加任何把请求与你关联的标识符——除了供应商本身已经看到的那些。

移除密钥后，下一轮对话 Socrates 就会停用。已经使用过该密钥的过往对话会被保留。
