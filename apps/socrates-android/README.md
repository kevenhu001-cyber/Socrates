# Socrates 原生 Android 客户端

使用 **Kotlin + Jetpack Compose** 全新实现，不是 Expo 换皮，也不使用 WebView 渲染聊天。源码位于 `apps/socrates-android/`，独立于现有 `apps/socrates/` Universal App；没有替换 Expo。此次获准修改 Web/后端，加入浏览器到原生的一次性安全登录交接；没有线上部署。

## 界面与交互

项目实际 Web/Expo 功能与服务端契约决定功能；参考图仅辅助布局和排版，不把图中的对话、答案、文件名、项目、插件、任务或图片嵌进正式应用。业务内容来自真实帐号接口，无数据时显示真实空态；测试公式和本地 HTTP 回复只放在测试源码中。布局和渲染应适应任意实际内容，不做截图式静态页面。品牌使用 Socrates。

按钮、图标按钮、字段、标签、卡片、菜单、弹层、提示、开关、单选、进度和抽屉均采用自有 Foundation/Canvas 设计，不使用默认 Material 业务控件。统一中文字号、行高和字重，使用系统无衬线、等宽代码和数学字体。保留聊天/工作切换与可手势关闭的侧栏；有消息时采用圆形菜单、新建/更多胶囊、浅色用户气泡和无卡片助手正文。底部输入栏支持收起/展开、多行、IME 避让、焦点保持和长消息跳到底部。

键盘由 Android 输入法提供，其按键、工具栏和语言切换外观取决于手机安装的输入法，不在应用里绘制假键盘。语音波形来自真实 RMS 音量；设备没有语音识别服务或拒绝权限时，会显示原因而不是模拟录音。

## 已实现功能

- 全屏自定义登录交接 UI，通过 Chrome 固定打开 `https://app.topodrive.top`，登录、注册和找回密码均在网页完成。网页显示账号并经明确确认后，通过短时、一次性、PKCE 绑定的代码及 HTTPS Android App Links 返回原生，换取独立 bearer/refresh 凭据并更新登录界面。没有原生凭据输入框、WebView 登录或隐式其他浏览器回退；Chrome 不可用、交接过期或系统禁止时显示错误。发布前必须完成真实签名指纹和域名关联配置，不能把本地通过等同于线上已可用。
- 加密令牌存储、401 刷新/重试、退出登录及切换服务器时清除凭据。
- 后端历史会话分页读取、会话搜索、新建、打开、重命名、置顶、归档/恢复及确认后永久删除；侧栏支持查看已归档会话。
- 输入框在胶囊、展开卡片和录音切换时保持同一个编辑器与输入连接，修复展开时重建导致失焦的问题；支持多行输入、IME 避让和宽度/圆角/高度动画。
- SSE 增量文本、思考过程、工具活动状态、取消回复、复制回复。
- 推理强度选择实际写入 reasoning_effort；设备 TTS 支持回复朗读/停止与离开前台释放。
- 原生通用 CommonMark + 扩展 Markdown：标题、段落、粗体/斜体、嵌套有序/无序列表、引用、链接、表格、删除线、任务列表、可横向滚动与复制的代码面板。不是按特定示例文字匹配的渲染器。
- 原生 LaTeX：接受 `$…$`、`$$…$$`、`\(…\)` 和 `\[…\]`，支持行内/居中块公式和引擎支持的分式、上下标、根式、积分、矩阵/对齐与框选等；代码保持原文，流式未闭合公式保持文字，闭合后排版。使用 Markwon 4.6.2 的原生 TextView spans 和 JLaTeXMath drawable，不使用 WebView，不执行模型 HTML/JS。CommonMark 在后台解析，公式共用有界线程池。不是完整 TeX 编译器，任意宏包/自定义宏不保证支持。
- Markdown 内嵌图片使用真实 data-URL 或公共 HTTPS 内容：无帐号凭据/无 Cookie、禁用重定向、拒绝私网地址、下载限 8 MiB、后台采样至最长边 2048。失败保留 alt 文字，不用示例图补位；需要鉴权的图像应使用已有资料库/消息附件契约。
- 回复/聊天文本可调用 Android 分享；另有真实会话分享链接的读取、创建、复制和撤销。消息菜单接入编辑重发、重新生成、分支以及真实反馈端点。会话内搜索支持跳到匹配消息。
- 圆角附件浮层调用真实系统相机、照片/文件选择器及资料库/插件入口。相机 FileProvider 只开放 `cache/captures/`，不共享任意本地路径；真实 data-URL 消息图片可采样预览。图片作为多模态附件发送，文档通过后端提取文本后作为对话背景发送。单附件上限 20 MB，图片上限 8 MB；文档文本上限 100,000 字符。
- 资料库：全屏两列资源卡片、真实搜索与 MIME 图标；上传（25 MiB 上限，仍受服务端配额/文件类型约束）、元数据详情、重命名、确认删除及真实附加到对话；不会只发送文件 ID 冒充附件。
- 图像：帐号真实图片的两列缩略图、搜索、详情、附加对话与删除。下载带鉴权且限 8 MiB；后台采样至最长边 512、并发 2、VM 缓存上限 12 MiB，重新打开时清空以隔离帐号；失败时显示失败而非示例图。可用真实提示词创建图像，依赖服务端图像模型配置；没有假热门/模板或完整图像编辑器。
- 项目：创建、描述/系统提示编辑、详情、删除、绑定项目对话，以及已有会话移入/移出。服务端没有独立项目—文件关联接口，不用删除文件模拟解除关联。
- 助手：创建、指令编辑、详情、删除及通过 assistantId 绑定的助手对话。
- 定时任务：依据真实状态筛选，不硬编码截图中的推荐任务；名称、提示词、重复频率、含时区的未来首次运行时间、编辑、启停、立即运行及删除。实际执行依赖服务端调度器，不是手机后台常驻任务。
- 插件：帐号已安装目录、详情、启停、删除；没有独立 marketplace、OAuth 授权或原生配置编辑器，创建条目不等于接通外部服务。
- Codex：读取真实能力与运行记录，可转编程对话；没有原生代码工作区编辑器和执行控制，不伪造这些能力。
- 工作区提供上述全屏页面入口；目录搜索真正过滤帐号数据，未获接口支持的共享/收藏/文件夹分类不伪造。各页包含加载、失败重试、空态及删除确认，保存失败保留表单输入。

- 记忆：真实列表、禁用筛选、分页、创建/编辑、启停和确认删除。
- 模型与服务商：真实列表、创建/编辑、激活、删除和多模态开关。只调用普通用户服务商接口，不把管理员系统模型配置接口当作目录。
- 学习：真实模型逐题生成测验/诊断、作答、规则评分与解析、历史重开、服务器 examData 保存；诊断题按项目契约保存在按服务器/账号/会话隔离的本机加密草稿，知识节点与教学计划同步服务器。导师聊天接入专用提示与实际阶段枚举，但仍缺少完整五方面知识建模、自适应教学、错题/重做/快照/练习分支。
- 工具活动：真实调用/结果/进度合并，保留输入、结果、错误、来源与附件信息，提供通用展示；不把通用详情称为 Web 所有专用交互卡片已对齐。

现有会话/消息的未知 wire 字段在读写时保留。`POST /sessions` 的摘要响应合并到完整原始数据，避免丢失消息或学习载荷。详细功能基线、缺口与验收边界见 [PARITY.md](PARITY.md)；当前**尚未完整对齐项目全部功能**。

## 后端连接

默认 API：`https://app.topodrive.top/api/v2`，与现有 Universal App 一致。打开侧栏 → 底部头像 → **连接设置** 可修改地址，须保留 `/api/v2` 路径。切换地址会退出当前帐号；应用不会把原服务器凭据带到新服务器。

Chrome 登录地址始终是指定的站点，不随 API 设置更换。网页 HttpOnly `sid` Cookie 与原生 bearer/refresh 凭据保持独立，不能读取或复制浏览器 Cookie。新增 `/auth/mobile/browser/authorize` 与 `/auth/mobile/browser/exchange`：前者强制浏览器 sid、同源 Origin 和完整 CSRF 配对，后者只接受一次性代码和匹配 verifier。代码五分钟过期、仅存散列并在数据库事务中原子消费；原生 pending 十分钟过期且保存于加密存储。固定返回地址为 `https://app.topodrive.top/auth/android/callback`，不接受自定义回调或 scheme 降级。自定义 API 连接不能使用生产浏览器交接，不会收到生产代码、verifier 或凭据。部署要求见 [browser-login-deployment.md](docs/browser-login-deployment.md)。

使用现有接口：`/auth/mobile/login`、`/auth/mobile/refresh`、`/auth/mobile/logout`、`/auth/me`、`/sessions`、`/chat/stream?sessionId=…`、`/files/extract` 及账号真实资源 CRUD/分享/消息反馈/记忆/服务商接口。HTTP 仅允许 Debug 版本连接 `localhost`、`127.0.0.1`、`::1` 或 Android 模拟器宿主 `10.0.2.2`；Release 禁止明文。API 密钥仍由后端管理，APK 内不包含模型服务密钥或帐号密码。

## 构建与测试

需要 JDK 17（本地亦已使用 JDK 21 编译至 Java 17 字节码）、Android SDK 35 / Build Tools 35.0.0。可通过 `ANDROID_HOME` 或被忽略的 `local.properties` 配置 SDK。

```bash
cd apps/socrates-android
./gradlew assembleDebug testDebugUnitTest lintDebug assembleDebugAndroidTest
# 已连接 Android 设备/模拟器时：
./gradlew connectedDebugAndroidTest
```

版本 **1.4 / versionCode 5**。本轮已从源码执行并通过 `assembleDebug testDebugUnitTest lintDebug compileDebugAndroidTestKotlin`，70 项 JVM 测试通过、无失败或跳过；没有执行设备测试。Debug APK：`app/build/outputs/apk/debug/app-debug.apk`，已随最终代码重新构建，但它使用开发测试签名，不是生产发布包。独立 CI：`.github/workflows/native-android-build.yml`，不替换现有项目 CI。

现有测试源码覆盖 SSE、资源与数学渲染、API 认证/刷新、路径隔离、wire 保存和聊天请求。新增 PKCE 标准向量、严格回调来源/状态/有效期和生产 API 隔离的 JVM 测试；Chrome 启动、错误与 UI 交互的 AndroidTest 源码仅编译，未在设备执行。服务端交接在隔离 PostgreSQL 上完成真实 HTTP 契约测试；Web 使用本地构建及模拟 API 做浏览器回归。这些都不等于真实生产账号从 Chrome 返回 Android 的实机验收，MockWebServer 也不作为运行时业务回复来源。

**设备测试包构建成功不等于设备执行通过。** 环境没有 KVM，软件模拟器已出现 Android 系统 Watchdog 超时重启；最终设备执行结论以交付日志为准。未获得稳定设备结果时，不声称屏幕上的公式排版、真机键盘交互、逐像素对齐或性能已经验收。生产帐号、真实邮件/模型、定时执行及插件调用仍需目标服务联调，不能以本地夹具替代。

## 性能设计与当前边界

主界面采用稳定消息 key 的 LazyColumn；网络运行在 IO 线程；流式文本以 32 ms 批次合并，仅有新增内容时刷新 UI；抽屉、切换与输入栏使用 Compose 动画和系统 Insets。语音服务在离开前台或销毁时释放。

**不能把架构选择等同于已达到某产品的性能。** 仍需在目标真机测量长对话、长代码块、IME 动画、掉帧、内存和耗电。没有真机数据时不承诺 60/120 fps。

当前不包含完整双向实时语音通话、复杂交互式 artifacts、完整自适应教学、离线发送队列或后台流式任务保障。帐号资料遵循后端只读限制。语音识别能力与联网要求取决于设备安装的 Android 识别服务。正式发布还需要发布签名、真实帐号联调和目标设备验收。
