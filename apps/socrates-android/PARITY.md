## 上一轮：按手机正文比例计算原生行距
- 核对 `frontend/src/styles/index.css` 的导入顺序及 `components/chat.css:54–64`：手机正文为 `15px × --app-font-scale`、行高 `1.65`。不能只读 CSS fallback 就把原生正文缩到 15sp：`frontend/src/displayPrefs.ts:11–18,176` 默认 M 档实际写入 `1.125`，因此默认 Web 手机字号为 **16.875px**，普通行高为 **27.84375px**。保留既有 Android **17sp**、sans-serif 和字重；不将 CSS px 与 Android sp 数值接近视为像素验收。
- Android 原正文使用 `TextView.setLineSpacing(7sp, 1)`，这是在字体 ascent/descent 高度上加 7sp，**不是 17sp + 7sp = 24sp 行高**，也不能保证同一相对节奏。新增独立 `NativeReadingTypography`，仅为正文计算 `max(0, 17sp 的实际像素值 × 1.65 − 原生字体 ascent/descent 高度)` 作为额外行距；普通基准目标约 **28.05sp**，更高的原生字体不强行压缩。根正文、列表/引用正文和深层 span 回退共用接线；复用 TextView 在密度/字体缩放变化时重新设置字号与补差。列表编号行高与圆点/只读任务标记的首行宿主同步该比例，保持原有自定义绘制、颜色、缩进和条目间距。
- 不改 `NativeMarkdown` 的公式插件字号（行内 17sp、显示乘数 1.16）、标题倍率、正文解析或表格；公式/图片 span 与标题仍可按原生规则扩展各自行高，不裁切到固定高度。表格继续独立 **14sp + 7sp 额外行距**，表头字重、列宽和滚动不变。`SocratesTheme` 的 bodyLarge 16/24、bodyMedium 14/21 等属于应用其他 Compose 文字角色，不覆盖原生 Markdown，故不全局改主题。选择/复制、软换行、链接与 drawable 生命周期、代码/生成中面板、流式/最终态均保持原路径。

## 上一轮：真实作品快照的有界本地只读差异
- 已核对现有 `GET /api/v2/artifacts/:id/versions` 确实返回各历史记录的 `source`；本轮直接复用已鉴权、已校验归属及预算的内存原文，不新增网络请求或猜测远端差异/恢复端点。历史读取仍需用户显式触发；缺失初版不补造，当前与历史分开读取、非事务快照的限制不变。

- 纯 Kotlin 逐行 LCS 比较保留空格、大小写、Unicode 和 LF/CRLF/CR 及末尾缺换行；每行明确“不变 / + 新增 / − 删除”、两侧真实行号和行尾，汇总新增/删除行数。不做字符级标注、模糊语义或格式化，也不将行尾差异隐藏成相同原文。替换按删除与新增计数，重复行采用确定的匹配顺序。
- 本地对比预算独立于原文读取预算：每侧最多 **120,000 个 UTF-16 单元、1,000 行**；含边界的 `(起点行数 + 1) × (终点行数 + 1)` 最多 **1,000,000 个 LCS 格**（Int 表约 4 MiB）。因此两个 1,000 行输入可能因组合预算被拒绝。超限返回明确原因、不生成部分差异；较大作品仍可关闭对比并使用原有分段阅读，不扩大 API 或阅读预算。
- 计算在 `Dispatchers.Default`，结果只回到仍有效的原生面板；输入变动销毁旧计算协程、结果、页码与复制反馈。关闭对比、重新读取作品、资源切换与账号页面清理沿用父阅读面板的记录身份销毁，不落盘、不跨账号缓存、不后台轮询。已开始的纯计算可能短暂继续，但预算有界且取消检查阻止回写。

- 本轮仅补齐 Artifact 原文级本地只读差异，不是远端恢复、编辑器、发布、运行预览或完整工作区；也不代表 Codex/Agent 文件差异已实现。所有前置未提交工作保留，仅新增/接入原生 Android 及回归说明；无 Web/Expo/后端修改、fetch、设备/模拟器验证、生产联调、部署、提交或推送。最终代码级验证见文末。

## 上一轮：系统文件与照片多选

- 一个批次持有同一忙碌/加载身份，逐个读取、提取/压缩和上传；以“当前已有附件 + 此前暂存项”检查图片/文字总预算。全部成功后一次性追加到草稿，保持原项及其顺序/稳定身份。任一项失败或草稿失效即停止，不把部分新项写进草稿，也不删除/编辑原项。远端上传不是事务，失败前已上传的文件可能仍在资料库；错误明确说明这一点，不做补偿删除。
- 沿用现有每文件 20 MB（含流读取硬上限）、图片源 8 MB、图片压缩与单图 2,000,000/合计 4,000,000 字符、提取文字与含包装 200,000 字符总预算；不扩大类型支持。非图片仍走真实提取接口并拒绝无可提取文字的文件，上传继续由服务端验证 MIME/实际文件内容。不是支持所有 `*/*` 所列文件格式。

- 只补齐原生系统批量选择；不改既有附件排序和消息级文字编辑语义，不写资料库原件，不宣称原件脱敏或限制工具读取原件。无 Web/Expo/后端改动、设备/模拟器验证、部署、提交或推送；此前未提交改动全部保留。代码级验证见文末。

- 严格区分后端的两条执行路径：普通 `native` 任务仅将结果写入关联会话，不生成独立运行记录；Codex 工作区任务才生成 `lastRunId`。无独立记录不会被显示为“从未执行”。展示任务元数据、最近独立运行状态、完整普通文本摘要/错误、真实时间与产物元信息；等待审批只说明当前视图不支持审批，不暗中批准或伪造工作区操作。没有展示原始事件载荷或声称完整运行日志。
- 关联会话由用户点击后鉴权读取，以自定义原生惰性列表只读展示真实标题与消息原文，明确会话可包含其他轮次、不将每条消息归因于本次运行。不替换当前聊天、不清空草稿或附件，不把缺失/已删除的会话当作空结果。摘要、错误和消息正文可选择复制；附件只说明正文未展示，不伪造文件预览。
- 刷新、切换任务、返回、关闭资源页或失去登录态均取消并使旧读取失效；加载失败可重试，独立 run 404 时保留任务真实会话入口；401 清空本页账号数据并交由现有登录门禁处理。没有自动轮询、后台调度器或新的第三方请求。
- “立即运行”继续调用真实同步 POST，严格按更新后的 task 行处理，不误当成 run；服务端返回失败任务也不提示“执行成功”。成功响应后打开执行结果；网络超时/5xx 明确说明请求未确认、可能仍在执行，要求先查看并刷新，客户端不自动重发。
- 新增执行契约、精确关联、返回值、失败/401、取消和只读会话状态回归，以及 5 项 Compose 回归源码。验证结果以本文末尾边界为准；仅修改 Android，保留前轮全部未提交改动，不改 Web/Expo/后端，不提交或推送，不运行设备。

## 上一轮：跨会话全文搜索

- 服务端按账号隔离，包含归档会话，使用 PostgreSQL `plainto_tsquery('simple', ...)`；不是任意子串匹配，不承诺中文逐字/任意片段都能检出。接口没有分页、总数、标签/日期/项目筛选，原生不伪造这些能力；未接入 schema 中虽声明但实现未支持的 artifacts/memory 范围。

## 上一轮：资料库文档与 PDF 基础预览

- 本阶段首次交付时仅有文档文字和 PDF 分页阅读；后续已补原生 1–4 倍缩放、平移及提取文字内搜索。Office 原版式预览、PDF 原件搜索/批注、OCR、多附件编辑与完整长文档工作区仍未实现。没有添加示例业务内容或设备截图，测试数据仅在测试源码中；新增 Compose 回归只编译、不执行。

## 容易误判的契约

`POST /sessions` 返回的是标量摘要，不返回完整消息、`examData` 或教学计划。客户端必须把摘要合回原始会话，不能用摘要替换全部数据。

`tutorData` 的诊断题与选项在 Web/Expo 契约中本来就是本地字段，后端会剥离；服务器只同步支持的知识节点、计划、阶段等。Android 因此使用按服务器、已验证账号和会话隔离的本机加密草稿保存诊断，不声称诊断题跨设备同步。保存失败会显示错误和重试入口，不再忽略响应。

`GET /system-models` 属于独立管理员会话，不是普通用户的模型列表。普通用户服务商走 `/api-keys`，激活后由后端实际选路。

图片附件应使用真实 `mime`、大小与持久文件 ID；内联 `dataUrl` 有后端限制。跨端历史未知字段需要保留，不能只保存当前原生 UI 认识的字段。
