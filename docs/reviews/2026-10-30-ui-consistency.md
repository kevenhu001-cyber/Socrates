# 前端 UI / UX 一致性检查（2026-10-30）

范围：当前 frontend SPA 的共享控件与 Intelligence UI。Universal App 未在本轮验证。

## 发现与规则

| 表面 | 当前情况 | 收敛规则 |
| --- | --- | --- |
| 共享按钮 | shadcn 使用 rounded-lg 与 min(radius-md, px)，OpenUI 使用 row 半径 | 交互控件使用 ui-radius-control；图标圆盘继续使用 pill；列表行使用 row |
| 密度 | 桌面 36、普通表单 40、触屏 44，移动目录有独立参考 | 保留表面对应尺寸；统一令牌和布局节奏，不全局覆盖 button |
| 卡片排版 | 已有统一主题与 spacing，但复杂组件需要自己的布局约束 | 标题/说明间距 xs，内容区 lg，卡片内边距 lg–xl，窄容器自动堆叠 |
| 智能交互 | 已支持表单、图表、SVG、地图、Visualization 和隔离脚本仿真 | 新能力通过声明式组件目录暴露，模型只选择语义与参数 |
| 物理教学 | 通用仿真需要生成脚本，缺少开箱即用的教学组件 | 增加 Simulation 理想抛体实验，可与已有 Text、Chart、Card 组合 |

## 本轮实现

共享 shadcn 按钮、OpenUI 控件使用同一圆角令牌。新增 Simulation，支持初速度、角度、重力、轨迹、时间拖动、播放/暂停和重置。参数变更重置播放；卸载清理动画。中英文标签随应用语言切换。模型提示与参数 schema 从同一目录生成，服务端不导入 React。

示例：

```text
root = Col([Title("抛体实验"), Text("改变角度，观察射程变化。"), Simulation("理想抛体", 20, 45, 9.81)])
```

物理边界：同高发射与落地，无空气阻力，采用 SI 单位。坐标轴自动缩放，不能凭轨迹的屏幕斜率比较发射角；读数用于定量比较。这不是通用物理引擎。

## 后续设计范围

全站一致性还需要逐页检查设置、考试、资料库与移动导航，不能将本轮共享组件调整视为全部页面验收。复杂实验可继续增加弹簧、波动、电路等独立组件；任意模型脚本沿用已有隔离仿真路径。侧边成果工作区、版本比较和导出属于后续交互设计，本轮未实现。

本轮不涉及数据库迁移或 API envelope 变更。回退 Simulation 时，需同步重新生成模型目录；已保存包含该组件的 OpenUI 内容在旧客户端可能显示未知组件，因此部署时应协调前后端版本。

## 参考图驱动的第二轮视觉调整

用户提供的参考将参数、图表和解释直接融入对话。本轮默认内联外壳、Card、原生 panel/metric 及嵌入图表去除重复边框与背景；显式 soft 卡片、输入框、弹出菜单和画中画仍保留必要区分。默认内容间距缩为 md，滑块使用标签/轨道/读数单行布局，极窄容器回落两行；44px 操作区域不因视觉紧凑而缩小。仿真参数移到图形上方，坐标和时间读数保持可见。模型组件说明同步建议紧凑编排，避免多层 Card 和重复分隔线。
