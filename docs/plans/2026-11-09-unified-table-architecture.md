# Unified Table & Markdown Extension Architecture

> **Date**: 2026-11-09  
> **Status**: Implemented & Verified  
> **Target Scope**: Markdown GFM Tables, Intelligent UI Tables, OpenUI Tables, Visualization Fallback Tables, and Streaming Lifecycle

---

## 1. Core Principle & Architecture

The objective is **not** to force two fundamentally distinct paradigms (streamed static Markdown strings vs stateful React component trees) into a single polymorphic component. Rather, it establishes:

1. **Unified Container Contract**: Every table in the system is enclosed by a single, accessible, horizontally scrollable wrapper (`.ds-table-wrap`) containing a semantic table (`table.ds-table`).
2. **Unified Visual Design Tokens**: A shared set of CSS variables controls outer borders, border radii, surface header backgrounds, cell paddings, row hover states, and dark mode responsiveness.
3. **Unified Streaming Lifecycle**: Unfinished streaming tables render inside the exact same `.ds-table-wrap.is-streaming` container box, eliminating layout shift and visual jarring when rows complete.
4. **Hard Model Decision Boundaries**: Static textual data, factual summaries, and property comparisons must always be emitted as GFM Markdown tables directly in prose. The `render_intelligent_ui` table node is reserved strictly for interactive tables (paired with filters, controls, or `$state` bindings), supported by automated telemetry warnings on misuse.

## 2. Technical Implementations

### A. Marked Table Extension Pipeline
In [`frontend/src/render/markdownExtensions.ts`](file:///home/ubuntu/User/Socrates/frontend/src/render/markdownExtensions.ts):
- Leverages `marked.use({ renderer: { table(header, body) } })` to wrap GFM table output:
  - Preserves alignment attributes (`align="left"`, `align="center"`, `align="right"`) generated by marked's native tokenizer.
  - Adds accessibility attributes: `role="region"`, `tabindex="0"`, `aria-label="Data table"`.
  - Emits the standard design system classes: `.ds-table-wrap` and `table.ds-table`.
- Guarded by `__socratesTableExtension` against duplicate registration during HMR or multiple turns.
- Eagerly mounted in browser startup ([`frontend/src/vendor/init.ts`](file:///home/ubuntu/User/Socrates/frontend/src/vendor/init.ts)) and on lazy access in the renderer ([`frontend/src/render/markdown.ts`](file:///home/ubuntu/User/Socrates/frontend/src/render/markdown.ts)).

### B. Streaming Placeholder Alignment
In [`frontend/src/render/markdown.ts`](file:///home/ubuntu/User/Socrates/frontend/src/render/markdown.ts):
- The streaming table placeholder is wrapped in `.ds-table-wrap.is-streaming`:
  ```html
  <div class="ds-table-wrap is-streaming" role="region" tabindex="0" aria-label="Table loading">
    <div class="table-stream-placeholder shimmer-text"><span class="table-stream-icon">⊞</span> 正在生成表格…</div>
  </div>
  ```
- Ensures identical bounding box, borders, and margins before and after the table completes.

### C. Component Adoption of the Unified Contract
1. **Intelligent UI (`UiTable`)**:
   [`frontend/src/react/intelligence-ui/IntelligenceUiNodes.tsx`](file:///home/ubuntu/User/Socrates/frontend/src/react/intelligence-ui/IntelligenceUiNodes.tsx)
   - Wrapper: `<div className="ds-table-wrap intui-table-wrap" role="region" tabIndex={0} aria-label={caption || 'Data table'}>`
   - Table: `<table className="ds-table intui-table">`
2. **OpenUI Content (`Table`)**:
   [`frontend/src/react/intelligence-ui/openui/content.tsx`](file:///home/ubuntu/User/Socrates/frontend/src/react/intelligence-ui/openui/content.tsx)
   - Wrapper: `<div className="ds-table-wrap iui-table-wrap" role="region" tabIndex={0} aria-label={props.caption || 'Data table'}>`
   - Table: `<table className="ds-table iui-table">`
3. **Visualization Static Fallback (`renderVisualizationTable`)**:
   [`frontend/src/render/visualizationStatic.ts`](file:///home/ubuntu/User/Socrates/frontend/src/render/visualizationStatic.ts)
   - Wrapper: `<div class="ds-table-wrap visualization-table-wrap" tabindex="0" role="region" aria-label="...">`
   - Table: `<table class="ds-table visualization-table">`

### D. CSS Styling & Cleanup
- In [`frontend/src/styles/components/intelligence-ui.css`](file:///home/ubuntu/User/Socrates/frontend/src/styles/components/intelligence-ui.css):
  - Declares the single source of truth for `.ds-table-wrap` (overflow-x scrolling, subtle border, rounded radius, card background) and `table.ds-table` (surface header, padding, hover ghost backgrounds).
- In [`frontend/src/styles/parity/transcript.css`](file:///home/ubuntu/User/Socrates/frontend/src/styles/parity/transcript.css):
  - Binds `.ds-table-wrap` into the transcript spacing rhythm.
  - Maintains fallback rules for third-party raw `<table>` instances (`table:not(.ds-table):not(.intui-table)`), preventing accidental layout breakage.
  - Leaves `.ds-table` completely free from hacky `display: block` overrides on mobile since `.ds-table-wrap` natively handles scroll on all viewports.

### E. Model Routing & Telemetry Guardrails
- **Tool Description**: [`server/src/services/intelligentUi.ts`](file:///home/ubuntu/User/Socrates/server/src/services/intelligentUi.ts) explicitly dictates:
  > *"Tables in intelligent_ui are strictly for interactive/stateful data (bound to $state or paired with controls); for standard static comparisons, reference data, or textual summaries, ALWAYS emit standard Markdown tables in prose instead."*
- **Chat Policy**: [`server/src/lib/chatPolicy.ts`](file:///home/ubuntu/User/Socrates/server/src/lib/chatPolicy.ts) directs the model to write Markdown tables for static side-by-side comparisons.
- **Server Telemetry**: `validateIntelligentUi` detects standalone static tables without parent or state bindings and issues automated telemetry warnings:
  > *"Node \"tbl\": static table rendered via intelligent_ui; prefer standard Markdown tables in prose for static comparisons"*
