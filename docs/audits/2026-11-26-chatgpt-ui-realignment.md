### 与早先简报的冲突如何裁决

- 画布：通用 ChatGPT 桌面是 `#212121` 主区 / `#181818` 侧栏，但参考图是近黑 `#0e0e0e`。**保持现有 `#0e0e0e` 四级背景阶梯**，
  桌面与手机同一套，因此 `check-surface-ladder` 及其基线不动（改成 `#212121` 还会违背「深色模式 page 最暗」的角色顺序）。
- 用户气泡：保留海军蓝（桌面同样沿用），不改成 `#303030` 灰。
- 发送键：参考是蓝色圆盘，不是 ChatGPT 桌面的黑白圆盘；桌面同样采用蓝色，保持一个有颜色的主控件。
- 占位：参考网页版在首页和对话中都写「询问 …」，App 变体在对话中写「回复 …」。本轮两处统一为「询问 Socrates」，
  英文保持 `Ask Socrates`，避免同一输入框在两个界面说两种话。

## 本轮改动（按区域提交）

1. **输入框**：占位改为「询问 Socrates」（zh）；主按钮改为蓝色操作色圆盘（发送、停止、空草稿三态同色），空草稿且听写可用时显示
   `waveform` 图标并直接开始听写（`ComposerPrimaryControl.voice`）；手机外框圆角新 token `--ui-radius-composer-phone: 32px`；
   `+` 菜单打开时触发器填充改为 `fillPressed`。
2. **消息操作与时间戳**：用户行 复制 · 分享 · 编辑（删除仅桌面显示，手机走长按菜单）；助手行 复制 · 赞 · 踩 · 朗读 · 分享 ·
   重新生成 · 更多（分支、换个角度在更多里）；手机不再隐藏赞踩。新增 `ConversationTimestamp`：对话最早一条消息的
   `createdAt`（新对话取首次渲染时间），按「今天 / 昨天 / M月D日 HH:mm」显示；`--ui-radius-bubble` 24 → 28px。
3. **正文**：外链点状下划线 + ↗、隐藏行内 favicon；表格满宽、正文字号、统一细行线；引用胶囊放大到 22px；分隔线用 subtle；
   回到底部按钮改为画布底 + 强边框、无阴影；手机 h2 20px 粗体、h3 18px。
4. **Mermaid**：渲染队列按当前 `data-mode` 初始化主题（dark / neutral），切换主题时也用 neutral；卡片 24px 圆角 + 细边框，
   头部 elevated 底 + 图标 +「Mermaid」，视图切换改为图标分段胶囊（代码 / ▶ 预览，`aria-label` 保持 `Code` / `Preview`）。
5. **菜单与活动行**：`+` 手机菜单改为浮动卡片、宫格改成行、说明同行；模型菜单行左文右值；活动行标签不再撑满，箭头紧跟文字。

## 守卫与基线

- 未放宽任何守卫，未更新任何 shrink-only 基线。`check-css-debt` 维持通过（新增样式只用 token）。
- `check-surface-ladder` 基线不变：本轮不改背景阶梯。
- i18n：新增 `chat.time.today` / `chat.time.yesterday`，en / zh 同步；中文文案沿用全角标点。

## 已知差距（未在本轮完成）

- 手机表格仍是可横向滚动的 `display: block`，窄表不能拉满列宽。
- 未登录首页的「登录」胶囊与建议胶囊、App 变体的浮动圆形顶栏不在本轮范围。
- 没有「语音对话」模式；蓝色声波圆盘触发的是现有听写，与麦克风同一能力。
