# Socrates application visual system

> **Partly superseded on 2026-10-25.** The neutral scale and the application
> shell (top bar, sidebar, command palette) were rebuilt on the Geist system in
> ADR 0023 — the ladder now projects from the Geist surface steps, the dark
> canvas is `#0a0a0a` rather than an OLED black, and the shell follows Geist
> control forms (6px radius, 1px hairline, raised surface). The typography
> and geometry rows below are unaffected and still describe the application.

The Vite application keeps the marketing site's Geist Sans / Noto Sans SC
typography and the restrained monochrome hierarchy of the ChatGPT reference.
Socrates branding, features and the reference-pinned phone densities remain.

| Role | Default | Owner |
| --- | --- | --- |
| Navigation, controls, menus | 14px / 20px | `styles/tokens.css`, canonical component owners |
| Desktop brand label / mark | 18px / 24px | `styles/parity/sidebar.css` |
| Chat prose | 16px / 28px | `styles/parity/transcript.css` |
| Desktop page heading | 24px | `styles/features/surfaces.css`, `styles/polish/workspace.css` |
| Settings section heading | 20px | `styles/polish/overlays.css` |
| Landing greeting | 30px | existing home owner |
| Desktop controls / search | 36px / 42px | existing surface owners |
| Phone controls | existing 32 / 40 / 44px ladder and directory references | mobile owners |

`themes.css` remains the sole palette and is imported last. Light mode uses
white content, a quiet gray navigation rail and neutral hairlines. Dark mode
keeps its OLED black canvas with distinct navigation, card and control layers;
selected rows and placeholder text remain readable. Semantic colors belong to
links, validation and meaningful data, rather than decoration.

The stacking ladder stays in `tokens.css`: header 20, panels 30, menus 40,
backdrop 80, drawer 90, popovers 200, modal 400 and sheets 1600. Dialogs and
menus use their existing focus/portal primitives. Narrow desktop headers use
the actual available container width to reflow mode controls beside long
model names; phone layout remains separately owned.

Chinese `@font-face` declarations are derived from `site/fonts.css` with
`npm --prefix frontend run sync:site-fonts`. Vite bundles the exact existing
marketing font files onto the application's own origin. Unicode ranges keep
unused glyph subsets out of the initial download. The focused `siteFonts`
unit test verifies the generated manifest and shared asset paths.
